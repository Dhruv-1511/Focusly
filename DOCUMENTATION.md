# StudyHub Project Documentation

Welcome to StudyHub, the OS for high-performance students. This document outlines the core functionality of each page in the application.

## 🚀 Navigation & Page Roles

### 1. Landing Page (`/`)

- **Role**: Entry point and marketing overview.
- **Key Features**:
  - Dynamic hero section with "GET STARTED" actions.
  - Bento-grid showcase of the platform's "Neural Recall" and "Focus Lock" features.
  - Quick "SOLVE" search bar to jump directly into solutions for study obstacles.

### 2. Student Dashboard (`/dashboard`)

- **Role**: Your personal command center.
- **Key Features**:
  - Visualization of study streaks and XP progress.
  - Quick access to recently used tools and active planner tasks.
  - High-level performance metrics.

### 3. Problem Solver (`/problems`)

- **Role**: Immediate actionable advice for study struggles.
- **Key Features**:
  - Searchable database of common issues (Memory, Focus, Motivation).
  - "5-Step Solutions" that provide a clear roadmap to overcome specific obstacles.
  - "Problem of the Day" for continuous improvement.

### 4. Intelligent Planner (`/planner`)

- **Role**: Time management and task organization.
- **Key Features**:
  - Drag-and-drop task prioritization.
  - Daily/Weekly views for study sessions.
  - Deadlines tracking and integration with rewards.

### 5. Genius Tools (`/tools`)

- **Role**: Advanced productivity engines.
- **Key Features**:
  - **Neural Recall**: A spaced-repetition system (SRS) for long-term memory.
  - **Focus Boosters**: Quick tools to prepare for deep work.
  - **Resource Library**: Curated list of study materials.

### 6. Student Community (`/community`)

- **Role**: Collaboration and collective intelligence.
- **Key Features**:
  - **Q&A Forum**: Ask questions and get answers from peers and AI.
  - **Study Groups**: Join subject-specific hubs for focused sessions.
  - **Rewards**: Earn XP and "Community Rewards" (like Premium Planner) by contributing helpful answers.

### 7. Focus Lock (`/focus`)

- **Role**: Digital isolation for deep work.
- **Key Features**:
  - Minimalist interface to reduce cognitive load.
  - Countdown timers and break reminders.
  - Ambient noise and focus-syncing features.

### 8. XP & Rewards (`/rewards`)

- **Role**: Gamification and motivation.
- **Key Features**:
  - Level progression based on tasks completed and problems solved.
  - Badge system for reaching milestones.
  - Leaderboards to see top performers in the community.

### 9. Mental Wellness (`/mental-health`)

- **Role**: Holistic support for students.
- **Key Features**:
  - Stress management tips.
  - Guided focus exercises.
  - Burnout prevention strategies.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS with custom Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
